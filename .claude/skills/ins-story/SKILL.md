# ins-story：限時動態

貼文是讓陌生人找到你；**限動是讓已經追蹤你的人，決定你是不是值得信任的人**。
限動只有追蹤者看得到，所以它的任務是加深關係，不是擴大觸及。

## 開始前

讀 `社群/合規規範.md`、`社群/我的語氣.md`。限動一樣算對外內容，合規規範照樣適用。

## 每天的結構：3 到 7 格

```
1     開場   今天真的發生的事，有臉或有手入鏡
2–3   內容   過程、結果、學到的事
4     互動   一個貼紙：投票、問答箱、測驗或連結
5     收尾   公布答案、結果，或預告明天
```

互動放第 4 格，不要放第 7 格。每多一格，看完的人就少一些。

## 貼紙怎麼用

| 貼紙 | 用途 | 保險業適合的用法 |
|---|---|---|
| 投票 | 最容易按 | 「你家保單放哪？抽屜／不知道」 |
| 問答箱 | 收集大家的原話 | 「關於住院理賠，你最想問什麼？」→ 每個問題都是下一支短影音（#16 原話提問） |
| 測驗 | 讓人猜錯再學 | 「住院一定要住滿三天才能理賠？對／錯」 |
| 連結 | 唯一能點的地方 | 連到你的網站文章 |
| 倒數 | 有日期的事 | 新制上路日、講座日期 |

問答箱最被低估：每一個回答都是用觀眾自己的話寫好的題目。

## 規則

- **第一格要有臉或手。** 純文字色塊最容易被跳過。
- **一格一個重點。** 沒有人會在限動讀一段話。
- **字放中間**：1080×1920 畫面，上面 250、下面 320 像素不要放字。
- **對一個人說話**：用「你」，不用「大家」。
- **轉發自己的貼文要加一句話**，說為什麼值得回去看。

## 保險業特別注意

- 投票和測驗**不碰錢**：不問「你每月存多少」「你覺得保費貴不貴」。
- 問答箱收到個人健康、保單細節的問題，**不在限動公開回答細節**，改私訊，並提醒對方不要傳身分證、病歷照片。
- 不在限動貼客戶的對話截圖、理賠單據，就算打了馬賽克也不建議。
- 不在限動做促銷：沒有限時優惠、送禮、停售倒數。

## 讓人自己開口（私訊漏斗）

限動點出一個問題 → 投票或問答箱讓人說「我也是」 → **對方回應後**你再私訊。
**對方先動，你才回。** 不要大量私訊沒有互動過的人，這會讓帳號被限制，也容易被檢舉。
私訊交給 `/ins-dm`。

## 交稿格式

```
限動・週二・5 格

1 [自拍，走在醫院走廊]   「今天陪客戶辦理賠，又看到同一個問題。」
2 [手拿文件，不露資料]   「診斷證明的日期，跟住院日期對不上。」
3 [說話]                 「出院前多看一眼，可以少跑一趟。」
4 [測驗]                 「診斷證明出院後還能補開嗎？能／不能」
5 [文字＋照片]           「答案明天公布。想要完整清單，回覆我。」

之後：每個回覆的人，一對一回。

檢查：check.py 未發現高風險字詞
狀態：草稿，發布前請依公司規定送審
```

不發文。使用者自己發。
