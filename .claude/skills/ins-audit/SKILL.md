# ins-audit：檢討自己的貼文

一個帳號什麼有效，唯一誠實的來源是這個帳號自己。所有教學（包括這套技能）都只是預設，使用者最近 30 篇才是證據。

## 輸入

使用者有什麼就給什麼：
- 每篇的洞察數據：觀看、觸及、互動、觀看時間、收藏、分享、追蹤、非粉絲觸及比例。截圖也可以。
- 或是最好和最差幾支短影音的**留存曲線**。這一張截圖比其他加起來都有用。
- 或是只有貼文和觀看數，也能先做一輪。

也讀 `社群/發文紀錄.md`，裡面有每篇用了哪個 hook 公式。

## 算這些，不要只看觀看數

| 指標 | 怎麼算 | 告訴你什麼 |
|---|---|---|
| **倍數** | 觀看 ÷ 自己帳號的中位數 | 這篇是真的好，還是普通的一天 |
| **非粉絲觸及** | 觸及中非粉絲的比例 | 有沒有被推出去 |
| **3 秒留存** | 3 秒還在的人 ÷ 開始看的人 | 開頭有沒有用。這就是開頭的成績 |
| **平均觀看時間** | 洞察直接給 | 中段有沒有用 |
| **分享率** | 分享 ÷ 觸及 | 最強的訊號：有人願意掛名轉傳 |
| **收藏率** | 收藏 ÷ 觸及 | 保險內容特別重要：被收藏代表有用 |
| **追蹤率** | 追蹤 ÷ 觸及 | 個人檔案有沒有接住人 |

用倍數、分享率、收藏率排名，不用觀看數。4,000 觀看、90 次分享，贏過 60,000 觀看、11 次分享。

## 找規律

前五名和後五名並排，願意說出使用者不愛聽的結論：
- **3 秒留存**：前後段差在這裡，就是開頭的問題，其他都是次要。
- **hook 公式**：前五名用了哪些編號。
- **形式**：短影音、輪播、單圖。
- **長度**：15 秒內、15–30、30–60、60 秒以上。
- **主線**：保險白話、理賠實務、家庭照顧、健康、日常。
- **第一小時有沒有回留言。**
- **星期和時間**：最後才看，而且只在其他都看不出來時。幾乎從來不是原因。

結論要附證據和可信度。30 篇看得出規律，6 篇看不出來，直說比硬湊好。

## 最省時間的一個區分

**有觀看沒追蹤，不是內容失敗，是個人檔案的問題。** 沒觀看才是開頭的問題。
非粉絲觸及高、追蹤率低，就不要再改開頭了，交給 `/ins-profile`。

## 保險業特別注意

- 表現好的貼文如果其實踩到合規邊緣，**不建議「多做這種」**，改建議用同樣的形式做合規的題目。
- 不要因為「存錢」「報酬」類的題目數字好，就推薦繼續做。
- 截圖裡有留言者帳號，整理時不要把個人資料寫進檔案。

## 輸出

```
檢討・31 篇・6/12–9/5・觀看中位數 1,100

倍數前五名
  8.2x  #16 原話提問  9,000 觀看  非粉絲 62%  3秒留存 71%  分享 48  收藏 120
  ……

後五名
  0.3x  #11 清單       330 觀看   非粉絲 9%   3秒留存 31%  分享 0
  ……

數據說了什麼
1. 3 秒留存就是全部：前五名平均 66%，後五名 33%。
2. 用客戶原話開頭的五篇，平均 5.1 倍，其他 0.9 倍。n=5，最強的訊號。
3. 單純清單有觀看沒收藏，後五名有三篇。
4. 星期幾看不出差別，不用再研究。

停止：純清單短影音
多做：客戶原話開頭、有自己經驗的
```
