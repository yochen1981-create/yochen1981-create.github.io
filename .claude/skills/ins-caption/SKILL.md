# ins-caption：文案

檢查工具在 `/ins-human` 的資料夾：

```bash
python3 ../ins-human/check.py 文案.txt --caption
```

它會檢查：合規字詞、第一行長度、hashtag 數量、呼籲次數、有沒有放連結、AI 味。

## 先決定這篇文案的任務

**任務 A：影片已經有開頭了。** 短影音前兩秒已經抓住人，文案不要再搶第二個開頭。文案負責：唯一的呼籲、讓呼籲合理的背景、別人會搜尋的字。

**任務 B：文案就是內容。** 單張圖、輪播封面只有幾個字，第一行就是開頭，寫法跟短影音開頭一樣：具體、短，停在讓人想點「更多」的地方。

先說這篇是 A 還是 B。

## 結構

```
第一行   手機上大約只顯示 55 個字。任務 A：呼籲；任務 B：開頭。
         不用招呼語、不用 hashtag 或 emoji 開頭。
內文     短段落，段落之間空一行，2–6 段。搜尋關鍵字放這裡。
呼籲     只有一個：留言關鍵字、收藏、或分享給某人。
hashtag  最多 5 個，放最後一行；也可以不放。
```

上限 2,200 字，幾乎沒有文案需要寫到那麼長。

## hashtag 和搜尋

- Instagram 從 2025 年 12 月起，每篇最多 5 個 hashtag。hashtag 是分類標籤，不是流量開關。
- `#保險` `#fyp` `#推薦` 這種描述不了任何東西，刪掉。用具體主題：`#長照申請` `#住院理賠`。
- **不用** `#理財` `#存錢` `#儲蓄險` `#投資` 這類標籤，標籤也算招攬訴求。
- **搜尋看的是文案文字。** 把別人會打的詞寫進句子裡（「失智前兆」「住院理賠文件」），比塞 hashtag 有用。先問使用者 2–3 個想被搜到的詞。

## 規則

- **不放連結。** IG 文案的連結點不了。放個人檔案，或私訊。
- **只有一個呼籲。** 兩個等於沒有。
- **留言關鍵字要好打**：一個詞、沒有空格、沒有 emoji，影片裡也要講一次。送出去的必須是衛教資料或清單，**不是試算、建議書或報價**。
- **emoji 是標點，不是裝飾。** 每 100 字不超過 4 個。
- 輪播和圖片要寫替代文字。
- 公司要求的警語或揭露文字，照公司版本放。

## 步驟

1. 說明這篇是任務 A 還是 B。
2. 寫草稿。
3. 跑 `check.py 文案.txt --caption`。高風險一定改；中、低風險逐條說明要不要改，不要默默略過。
4. 交稿：

```
文案草稿
任務：A，影片已經有開頭
第一行：48 字，在 55 字內講完
呼籲：一個，留言「清單」
hashtag：3 個
搜尋詞：「住院理賠」在第 3 行，「理賠文件」在第 5 行
檢查：check.py 未發現高風險字詞
狀態：草稿，發布前請送公司法遵或主管審核
```

不發文。使用者自己貼。
