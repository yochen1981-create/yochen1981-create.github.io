# ins-repurpose：一份素材拆成一週

一份好的長素材，裡面有 4 到 6 篇貼文。多數人只拿走一篇，其他都丟了。

## 輸入

逐字稿、文章、講座筆記、課程心得、客戶常見問題整理。給網址的話，這次對話有工具就用，沒有就請使用者貼上。**整份讀完才開始拆。**
如果是使用者自己拍的影片，也請他給檔案：用他自己的畫面，勝過重念一次。

## 先過濾：哪些不能公開

保險業務員的素材常混著不能發的東西，先挑出來，列給使用者看：

- **公司內部資料**：商品教育訓練、內部數字、主管會議內容。沒經公司同意不公開。
- **商品內容**：商品名稱、保障內容、費率、試算。不在社群講，留給一對一並用公司核可資料。
- **客戶資訊**：任何可辨識的人、事、地、時。去識別化並先問過本人，否則拿掉。
- **理財、投資、信託、節稅**內容：不做成社群貼文。
- **別人的投影片、圖表**：講者的內容要標出處，不整段翻拍。

剩下的才進下一步。

## 拆，不是摘要

摘要不是貼文，沒有人想看摘要。整份找出能獨立成立的東西：

| 找 | 是什麼 |
|---|---|
| **主張** | 每一句會引起討論的話 |
| **數字** | 每一個數字、時間、比例（只用有出處的） |
| **故事** | 每一個有人、有場景、有轉折的時刻 |
| **原理** | 每一個「其實這件事是這樣運作的」 |
| **錯誤** | 每一個做錯了什麼的坦白 |
| **金句** | 每一句可以直接引用的話 |

先列出找到幾個，再開始寫。少於四個，代表素材太薄，硬拆出來的四篇也會很薄，直說。

## 選形式

- 主張、錯誤、故事 → 短影音（需要聲音和表情）
- 原理、清單、步驟 → 輪播（需要反覆看）
- 金句 → 限動一格，不做成貼文

## 排成一週

每篇完全獨立：觀眾沒看過原始素材，以後也不會看。**不要寫「上次影片說過」。**
每篇用不同的 hook 公式（`ins-reel/hooks.json`），五篇同一個開頭結構看起來就像量產。
最強的主張放第一篇、故事放週中、原理放最後。

## 輸出

```
素材：住院理賠實務講座筆記（約 9,000 字）

過濾掉：商品介紹段落（商品內容）、主辦單位內部數字、講者投影片原圖
找到：5 個主張、6 個數字、3 個故事、4 個原理、1 個錯誤、7 句金句

這週
二  短影音  #2 否定命令   別等出院後才想到要診斷證明
四  輪播    #11 清單＋最愛 住院理賠最常缺的 5 份文件
五  短影音  #16 原話提問   「門診手術也能申請嗎？」
日  短影音  #21 從句子中間 「……結果出院那天，才發現收據少了一張。」

說「寫週二」我就開始寫。
```

一次寫一篇，每篇經過 `/ins-reel` 或 `/ins-carousel`，再過 `/ins-human`。不要一次丟四份完整腳本，會全部長得一樣，使用者一支也不會拍。
