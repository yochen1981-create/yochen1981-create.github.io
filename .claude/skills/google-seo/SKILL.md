# 讓 Google 找得到我

## 第一次設定（只做一次）

先檢查網站，缺什麼就補什麼，每一步做完用一句白話告訴使用者：

1. **網站地圖（sitemap）**：確認網站有自動產生的網站地圖，讓 Google 知道你有哪些頁面
2. **每一頁都有標題和描述**：首頁、關於我、每篇文章都要有
3. **全名要出現**：首頁和關於我寫出完整姓名＋地區＋「保險業務員」，例如「高雄保險業務員 王小明」，別人搜你的名字才找得到
4. **名字一致**：網站、LINE、IG 用同一個名字
5. 改完說：「幫我發布更新」

### 交給 Google（要使用者自己操作）

帶使用者一步一步做，一次只講一步：

1. 打開 Google Search Console（search.google.com/search-console），用自己的 Google 帳號登入
2. 新增資源，選「網址前置字元」，貼上網站網址
3. 驗證：照畫面選「HTML 標記」，把那一行交給 Claude 放進網站，再發布更新後按「驗證」
4. 左邊選單點「Sitemap」，填入網站地圖的網址（先幫使用者查好正確的檔名再告訴他，常見是 `sitemap-index.xml` 或 `sitemap.xml`）
5. 告訴使用者：「Google 收錄要幾天到幾週，不用每天去搜。」

不要替使用者登入帳號；要他自己輸入密碼。

## 每篇文章的檢查（寫完文章就做）

| 項目 | 怎麼寫 |
|---|---|
| 標題 | 用客戶會打進 Google 的問法，關鍵字放前面（例：「實支實付要買幾張才夠？」） |
| 描述 | 70–90 字，說清楚這篇幫讀者解決什麼 |
| 網址 | 英文小寫＋連字號，短、看得懂（例：`medical-reimbursement`），發布後不要再改 |
| 開頭 | 前 100 字就回答問題 |
| 小標 | 用讀者會問的問題當小標 |
| 互相連結 | 連到 1 篇相關的舊文章，舊文章也連回來 |
| 圖片 | 每張圖寫一句說明畫面內容 |

## 保險業務員要避開的關鍵字

搜尋量再大也不用：存錢、理財、投資、報酬、節稅、基金、儲蓄險推薦、哪張保單最好、XX 保單比較。
改寫客戶真正會問的保障問題：「＿＿是什麼」「理賠要準備什麼」「＿＿怎麼申請」。

## 每月看一次成績

請使用者打開 Search Console 的「成效」，截圖給你，再用白話說明：
- 哪幾篇有人看到（曝光）、有人點（點擊）
- 「被看到很多次但很少人點」的文章 → 幫他改標題和描述
- 別人用什麼字找到他 → 下一篇文章的題目

最後問：「要不要幫你發布更新？」
