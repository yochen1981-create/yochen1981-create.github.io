# ins-viral：找爆款、做參考檔

其他技能負責寫，這個負責去看。每月跑一次，公式大約一季才會換。

這個資料夾有一個真的會跑的工具：

```bash
python3 swipe.py 收集.tsv --out 社群/爆款參考.md
```

## 最重要的觀念

**觀看數不是證據。** 兩百萬粉絲的帳號拿到 40 萬觀看，只是普通的一天；四千粉絲的帳號拿到 40 萬，是找到了什麼，而且可以學。

所以一律用**倍數**排名：這支的觀看 ÷ 該帳號最近的中位數。3 倍以上才算訊號，1.5 倍以下只是那個帳號的日常。

找的帳號大小，最好在使用者自己的 **10 倍以內**。

## 保險業特別注意：很多爆款是違規的

保險相關的熱門影片，有不少靠「存錢」「報酬」「比定存好」「這張必買」紅起來。
**學公式，不學違規的內容。** 每一列都標合規風險：

- 🟢 可以學：開頭結構、節奏、畫面安排都能用在合規題目
- 🟡 只學形式：題目碰到理財或商品，換成保障、理賠、照顧類的題目
- 🔴 不要學：靠違規內容紅的，形式也別抄，免得被聯想

## 步驟 1：挑帳號

請使用者給 6–12 個帳號，或你提議、他同意：
- **4 個直接**：同樣是保險業務員，稍微領先一點
- **4 個相鄰**：不同領域、同樣受眾（育兒、長照照顧、健康、在地生活）。最好用的形式常從這裡來
- **2–4 個大帳號**：只學形式，不學節奏和語氣

也請使用者打開自己的「已收藏」，那是最快、最合自己口味的資料。

## 步驟 2：去看

用這次對話能用的瀏覽工具（內建瀏覽器、使用者自己的 Chrome）。

**不能妥協的規則：**
- **不替使用者登入、不要密碼。** 需要登入的頁面，請使用者在場用自己已登入的瀏覽器，或請他貼上來。
- **是閱讀，不是爬蟲。** 10 個帳號、每個十幾支、用人的速度看。不寫爬蟲、不用爬蟲服務、不在背景重複跑。
- **學公式，不抄影片。** 學開頭結構、長度、剪輯節奏，不抄別人的稿子、語氣和畫面。每一列都標來源帳號。

每支記下：

| 欄位 | 說明 |
|---|---|
| account | 帳號 |
| followers | 粉絲數 |
| median | 看最近 12 支，取中間的觀看數 |
| views | 這支的觀看數 |
| hook | 第一句話（口播或字卡），照原文抄，錯字也照抄 |

中位數最重要，沒有它就回到用粉絲數排名，這正是這個技能要避免的。

## 步驟 3：排名

填成 tab 分隔的檔案（第一行是欄位名稱）：

```
account	followers	median	views	hook
@某帳號	48000	11000	412000	「住院一定要住滿三天嗎？」我每週都被問。
```

跑 `swipe.py`，它會算倍數、用 `ins-reel/hooks.json` 辨認公式、用 `hookscore.py` 打分，並比較前三分之一和後三分之一的差別。

## 步驟 4：說結論，要保守

只講三件事：
1. **哪些公式在前段班出現最多**，附次數。兩個公式各出現四次、橫跨六個帳號，才算發現。
2. **前段班結構上的共同點**：開頭長度、第一個畫面有沒有動作、呼籲放哪。
3. **沒辨認出來的那些**：要人工看，可能是 hooks.json 還沒有的新公式。

最後用白話說樣本數和可信度：40 支、6 個帳號才撐得起一個說法；12 支不行。

## 步驟 5：變成能拍的東西

前三名公式，各寫一個**使用者自己的版本**：他自己的故事、他自己的數字、合規的題目。交給 `/ins-reel` 並指定公式編號。
不要交回「拍一支像這樣的」，要交回他明天就能講的第一句。

## 輸出

寫到 `社群/爆款參考.md`，包含排名、合規標記（🟢🟡🔴）、結論、使用者版本的開頭。`/ins-reel` 和 `/ins-plan` 都會讀它。

這個技能只看，不發文、不追蹤、不按讚、不私訊。
