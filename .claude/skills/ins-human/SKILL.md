# ins-human：去 AI 味＋合規字詞檢查

這個資料夾有一個真的會跑的工具，一定要用：

```bash
python3 check.py 草稿.txt                    # 合規字詞＋AI 味
python3 check.py 文案.txt --caption          # 文案模式，多檢查格式
python3 check.py 草稿.txt --fix -o 乾淨.txt  # 刪隱形字元、破折號改逗號
```

在本機跑，不連網，不上傳。

## 它抓什麼

**合規字詞**（依嚴重度：高＝幾乎一定要改，中＝看上下文）
職稱（理財顧問、財務規劃）、存錢理財訴求、和定存或股票比較、保證保本、報酬配息、借錢解約、贈品折扣、推薦商品、停售急迫話術、恐嚇、個資、未核准商品、保單健檢。

**AI 味**
- 隱形字元（鍵盤打不出來，會跟著複製貼上，`--fix` 自動刪）
- 破折號（台灣日常文字很少用，`--fix` 改成逗號）
- 罐頭套話：賦能、打造、全方位、綜上所述、大家好、今天要跟大家分享、建議收藏……
- 模板句型：「不是……而是……」超過一次、「不僅……更……」、「A、B、C」三連排比、單獨一行的「結果呢？」
- emoji 太多

**文案格式**（`--caption`）
第一行超過 55 字、hashtag 超過 5 個、空泛 hashtag、呼籲超過一個、放連結。

## 它抓不到什麼（一定要說清楚）

這是**字詞比對**，不是法遵審核：

- 合規看的是**整體印象**：比喻（「這張就像存錢筒」）、諧音、emoji 暗示、圖片、「先否認再暗示」（「不保證，但基本上不會虧」）都算違規，工具多半抓不到。
- 沒抓到東西，只代表沒有出現常見的危險字，**不代表合規**。
- 不要因為工具沒抓到就說「沒問題」。只能說「已依規範檢查，未發現明顯問題」。

## 步驟

1. `check.py 草稿.txt --fix -o 乾淨.txt`
2. **合規高風險**：一定改，給替代寫法。拿不準的從嚴，標「建議先問公司法遵」。
3. **模板句型**：工具只標出來，要你自己重寫。保留意思，改成使用者平常講話的樣子。
4. 再跑一次 `check.py 乾淨.txt`，給使用者看前後差別。
5. 讀一遍 `社群/合規規範.md` 文末的自我檢查清單，補上工具抓不到的部分（比喻、圖片、整體印象）。
6. 交出：乾淨的全文＋檢查結論＋「最可能被截圖的一句」。**不要只給分數或結論。**

兩輪是正常的。改到第五輪還不行，代表草稿本身是套公式寫的，該重寫，不是繼續修。

## 口播稿多一步

唸出來試試看。唸起來卡、要換氣才講得完、聽起來像在背稿的句子，改短。

最後提醒：**發布前請送公司法遵或主管審核，並保留審核紀錄。**
