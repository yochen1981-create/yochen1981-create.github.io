# ins-profile：個人檔案

多數人改錯地方。個人檔案不是讓人逛的店面，是**決定畫面**：陌生人從一支影片點進來，大約 3 秒決定「這裡還有更多我要的嗎？」。

## 輸入

請使用者貼上或截圖：名稱欄、帳號、簡介、連結、精選動態名稱、置頂了什麼、前九格封面。
個人檔案上方加前兩排版面的截圖，就夠做第一輪。**不替使用者登入 Instagram。**

也讀 `社群/我的語氣.md`（名字、公司、正式職稱、關鍵字）和 `社群/合規規範.md`。

## 打分

讀本資料夾的 `rubric.json`：12 項、100 分，每項都有滿分長什麼樣、通常怎麼失分。
每項都打，列表，給總分。**要誠實**，第一次多半落在 30–40 分，給高分沒有幫助。

```
個人檔案分數  38/100

  名稱欄          2/12   只有名字，沒有任何人會搜尋的詞
  簡介第一行      3/12   三個名詞加一個咖啡 emoji
  身分與職稱合規  4/10   寫「理財規劃」，要改成公司核定職稱
  置頂三篇        0/10   沒有置頂
  ……
```

## 依扣分多寡改寫

一次只改幾項，使用者要真的去一欄一欄改。

1. **身分與職稱（合規優先）**：職稱照公司核定的寫，所屬公司名稱正確，依公司規定標示資格。這一項有問題，不管分數多少都**排第一個改**。
2. **名稱欄（30 字內）**：粗體那行，不是帳號。格式：`名字｜地區＋別人會搜的詞`。給三個選項。
   不用「理財」「財務規劃」當搜尋詞。
3. **簡介第一行**：給誰的、看了得到什麼。不是頭銜、不是形容詞清單。剩下的字放一個真實經歷或一個清楚的服務說明。不寫「保證」「省保費」「最划算」。
4. **置頂三篇**：最能證明你的、最清楚說明你做什麼的、最能認識你這個人的。四次點擊就能改，效果最大。
5. **精選動態**：4–6 個，用客戶會問的問題命名：關於我、理賠協助、保單整理、常見問題、服務流程。刪掉其他的。
   不要「客戶好評」截圖牆、不要「方案價格」「限時優惠」。
6. **連結**：一個，連到簡介承諾的地方，通常是個人網站。不連試算工具或商品頁。
7. **版面**：前九格縮圖。短影音封面要挑，放 4–6 個字。

## 合規提醒

個人檔案（名稱、簡介、精選動態）算對外的招攬資訊：
- 改之前，先請公司確認**正式職稱**和**資格標示方式**，有標準警語就照公司版本放。
- 精選動態、置頂裡有客戶資料（姓名、照片、保單、理賠單據、對話截圖）的，請使用者移除。

## 輸出

分數表，然後依序給可以直接貼上的改寫，每段先跑 `/ins-human` 的 `check.py`。
最後重新打分，誠實說改善了多少：改完是 84 就說 84，並說剩下的分數要靠什麼（通常是版面、限動習慣、一篇還不存在的置頂貼文），那些不是改字能解決的。

這個技能不會改任何 Instagram 設定。每一欄都由使用者自己改，並依公司規定送審。
