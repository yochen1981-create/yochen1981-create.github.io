# ins-reel：短影音腳本

把一個想法寫成有人會看完的短影音。

這個資料夾有兩個真的會跑的工具，一定要用，不要用感覺判斷開頭好不好、影片多長：

```bash
python3 hookscore.py hooks.txt              # 開頭三選一，排名打分
python3 hookscore.py --hook "一句話"         # 單句打分
python3 beats.py script.txt --target 45     # 分秒拍攝表
python3 beats.py script.txt --cps 5         # 語速：每秒幾個字（預設 4.5）
```

中文按字數算，好的開頭大約 8 到 20 個字。（在本技能資料夾執行）

## 開始前

1. 讀 `社群/合規規範.md` 和 `社群/我的語氣.md`。沒有的話先跑 `/ins-social` 建好。腳本要用使用者自己的口氣，因為他要唸出來。
2. 讀本資料夾的 `hooks.json`：26 個公式，每個都有模板、保險業範例、字卡版本、適合用在哪、**合規地雷**。
3. 想法太薄就不要硬寫。一次問完：發生了什麼事、跟誰、結果是什麼。短影音需要一件具體、真實的事。
4. 有 `社群/爆款參考.md` 就讀，那是 /ins-viral 找到的、同領域正在有效的公式，優先於預設。

## 結構

前 2 秒決定看不看，接下來 5 秒決定留不留。

```
0:00–0:02  開頭    口播第一句＋字卡，分開寫。第一個畫面要有動作。
0:02–0:07  為什麼  這件事跟觀眾有什麼關係，一句話。
0:07–      內容    一拍一個重點，每一拍換畫面。
最後 3 秒  收尾    兌現開頭的承諾，然後只有一個呼籲。
最後一句   回扣    呼應開頭的一個詞，重播時接得順。
```

長度：15 到 45 秒最好用，最長不要超過 60 秒。

## 步驟

1. **開頭三選一**：從 `hooks.json` 挑三個**不同**的公式，每個寫口播句＋字卡。
   跳過「合規地雷」踩到的公式（例如 #17 不能比較保單、#19 不能用停售當期限）。
2. **打分**：三句放進檔案，一行一句，跑 `hookscore.py`，把排名給使用者看。
   最高分低於 50，代表還沒有好開頭，改內容比改字有用。
3. **寫逐字稿**：用使用者平常講話的方式。短句、口語、不用排練就講得出來。
4. **量秒數**：`beats.py script.txt --target 秒數`，修掉每個提醒：開頭超過 3 秒、某一拍超過 4 秒、連續好幾拍沒有具體內容、沒有回扣。
5. **去 AI 味＋合規**：跑 `/ins-human` 的 `check.py`，有高風險字詞一定要改。
6. **交稿**（格式見下）。

## 字卡要另外寫

- 每張字卡 **6 個字以內**，第一張在第一個畫面就出現。
- 1080×1920 畫面，字放在中間：上面 230 像素、下面 480 像素、右邊 230 像素都不要放字（會被介面蓋住）。
- 內容段落要上字幕，多數人先靜音看。

## 保險業特別注意

- **一支只講一件事。** 有兩件就是兩支。
- **數字要真的。** 用自己的年資、經驗次數、官方統計（附來源）。**不用報酬率、配息、保費比較、理賠金額**當數字。
- **客戶故事去識別化**，而且先問過本人；拍攝畫面不能出現保單、病歷、對話截圖。
- **不提商品名稱、不推薦哪張保單。** 講觀念和實務，商品細節留到一對一。
- **呼籲只有一個**：收藏、分享給某人、或留言關鍵字（送的必須是衛教資料或清單，不是試算或建議書）。
- **不編造。** 缺數字就留 `{{你的數字}}` 並標出來。
- 開場不要「大家好」「今天要跟大家分享」。從重點開始。

## 交稿格式

```
REEL 草稿
開頭：#16 原話提問「住院一定要住滿三天嗎？我每週都被問。」 hookscore 78
長度：約 38 秒，11 拍，語速 4.5 字/秒
字卡：6 張
檢查：check.py 未發現高風險字詞；自我檢查清單已跑
最可能被截圖的一句：「……」→ 建議改成「……」
狀態：草稿，發布前請送公司法遵或主管審核

（逐字稿）
（字卡＋時間）
```

使用者說「好」，就存到 `社群/草稿/` 並在 `社群/發文紀錄.md` 記一行（日期、公式、分數、第一句、狀態「待送審」）。
接著建議跑 `/ins-caption` 寫文案。**這個技能只寫腳本，不發文。**
