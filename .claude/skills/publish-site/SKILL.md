# 幫我發布更新

## 步驟

1. 先檢查這次改了什麼（git status、git diff），用一句白話跟使用者確認：「這次要發布的是：＿＿＿，對嗎？」
2. 全部加入：`git add -A`
3. 用一句中文描述這次的修改當 commit 訊息（例：「新增文章：實支實付怎麼看」），執行 commit
4. 推上 GitHub：`git push`
5. 告訴使用者：「已經交給搬家公司了！Cloudflare Pages 大約 1–2 分鐘會自動更新，等一下重新整理你的網站就能看到。」

## 出狀況的時候

- push 失敗、要求登入或授權：一步一步用白話帶使用者完成（要開哪個網頁、按哪個按鈕），一次只講一步；提醒他看清楚是 github.com 官方畫面再按同意
- 有衝突或看不懂的錯誤：不要丟術語給使用者；先自己嘗試解決，解決不了就用白話說明現在的狀況和下一步
- 永遠不要執行會刪掉使用者內容的指令（例如 reset --hard、force push）除非使用者明確同意並了解後果
