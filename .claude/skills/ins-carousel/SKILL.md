# ins-carousel：輪播貼文

輪播是最容易被**收藏**的形式：要反覆看的東西做輪播，要有感覺的東西做短影音。

## 什麼時候用輪播

- 用：步驟、清單、檢查表、前後對照、名詞解釋、「理賠要準備什麼」
- 不用：一句話的觀點（交給 `/ins-reel`）、需要畫面和表情的故事

## 開始前

讀 `社群/合規規範.md`、`社群/我的語氣.md`。視覺照專案的品牌規範（my-brand 技能或 brand.md），沒有就用一個主色＋一個底色，不要自己發明一堆顏色。

## 結構：6 到 10 張

```
1        封面     6–12 個字的標題，縮圖也看得清楚；下面一行小字說你會得到什麼
2        為什麼   這件事跟你有什麼關係，一句話。這張也要能單獨看
3 到 N   一張一個重點：3–10 字小標＋最多 40 字說明
N+1      總整理   全部重點一次列出。這張是會被截圖、被轉傳的
最後     呼籲     只有一個：收藏、分享給某人、或留言關鍵字
```

## 文字規則

- **封面決定 80% 的成績。** 字要大、要少。
- **標頁碼**（3/8），看得到終點的人比較會滑完。
- **一張不放一段話。** 超過 40 字就拆兩張。
- **每張角落放帳號名稱**，截圖傳出去才找得到你。
- **字不小於 32px**（手機上看是實際大小的三分之一）。
- 封面要寫**替代文字**（給視障朋友和 Instagram 讀）。

## 保險業特別注意

- 清單內容用**公開、官方資料**（衛福部、健保署、公司核可資料），附來源。
- 不做「保單比較表」「保費試算表」「哪張最划算」「必買清單」。
- 理賠、條款類內容加一句「實際以保單條款為準」。
- 公司有標準警語或規定的揭露文字，放在最後一張。
- 圖片不放客戶的保單、單據、對話截圖。

## 步驟

1. 先給**每一張的文字**（編號清單），使用者 10 秒內看得完、可以先改。
2. 跑 `/ins-human` 的 `check.py`，有高風險字詞先改。
3. 文案交給 `/ins-caption`（輪播的文案要負責開頭，因為封面只有幾個字）。
4. 使用者確認文字後才做圖：寫一份 HTML，每張 `width:1080px; height:1350px`，照品牌規範的顏色和字型；封面重要的字離四邊至少 120 像素。用 Chrome 無頭模式或現有工具輸出成 PNG，存到 `社群/草稿/日期-題目/`。

## 交稿格式

```
輪播草稿・8 張

1 封面   住院前必帶的 5 樣東西
         第 4 樣最多人忘記
2 為什麼 少一樣，理賠就要多跑一趟。
3 ……
7 總整理 5 樣東西一次看
8 呼籲   收藏起來，住院前打開對一次

文案：交給 /ins-caption
檢查：check.py 未發現高風險字詞；自我檢查清單已跑
最可能被截圖的一句：「……」→「……」
狀態：草稿，發布前請送公司法遵或主管審核
```

不上傳、不發文。使用者自己發。
