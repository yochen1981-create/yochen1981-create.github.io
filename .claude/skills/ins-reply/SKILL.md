# ins-reply：回自己貼文的留言

貼文下的留言區決定這篇能走多遠：每個回覆都是一次互動，**發文後第一個小時**的回覆最有用。
但每則留言價值不同，所以先分類再寫。

## 輸入

使用者貼上留言（最好有帳號名稱），截圖也可以。不要用瀏覽器去抓。

## 先分類，說出每類幾則

| 類別 | 是什麼 | 怎麼處理 |
|---|---|---|
| **關鍵字** | 留了你指定的關鍵字 | 回一句，再私訊送出承諾的東西 |
| **潛在客戶** | 描述了你能幫忙的狀況 | 公開回一個真的有用的答案，最後一句開一扇門 |
| **有內容** | 補充、不同意、延伸 | 整串最長的回覆 |
| **好問題** | 很多人都會有的問題 | 這題該做成一支短影音，不只是回覆 |
| **支持** | 「讚」「好實用」、標記朋友 | 按讚，回 3–8 個字 |
| **雜訊** | 推銷、廣告、惡意、釣魚 | 不回，或一句話結束 |

照這個順序寫，價值沒了就停。

## 最多人忽略的一招

很多人都有的問題，**用一支短影音回覆**。Instagram 會把那則留言貼在新影片上，提問的人會收到通知。
把符合的問題標出來，交給 `/ins-reel`，用 #16 原話提問。

## 怎麼回

- **回答真正的問題。** 問怎麼做就告訴他怎麼做，不要硬把人導去私訊。
- **用對方的名字一次**，放開頭，不加驚嘆號。
- **長度對齊。** 四個字的留言不需要四行回覆。
- **遇到批評**：先承認對的部分（用他的話），再說你的立場。不刪、不防衛、同一串不回第二次。
- **遇到惡意**：不回。回覆就是給他曝光。辱罵可以隱藏，這不是認輸。
- **遇到潛在客戶**：公開把通用的部分答完整。最後一句是「如果想看你自己的狀況，可以私訊我」，是幫忙，不是推銷。

## 保險業特別注意

- **個人保單、健康、理賠細節不在公開留言回答。** 公開只回通用原則，細節請對方私訊，並提醒「不用傳身分證或病歷照片」。
- 有人問「哪張保單比較好」「XX 公司的好不好」：**不比較、不評論其他公司或商品**，回「要看每個人的需求，條款以保單為準，有需要可以私訊我一起看」。
- 有人問報酬、儲蓄、要不要解約換新：不在留言討論，改私訊並依公司規定處理。
- 不在留言區報價、提供試算。
- 同業來酸：不回嘴，不批評同業。
- 回覆一樣跑 `/ins-human` 的 `check.py`。

## 關鍵字留言

如果這篇有關鍵字呼籲，這些留言就是重點：每一個都是舉手的人。逐一回覆，再送出承諾的東西（衛教資料、清單）。
用 Instagram 官方的自動回覆工具可以；**不要大量私訊沒有留言的人**。

## 交稿格式

```
回覆・84 則留言・關鍵字 41、潛在客戶 2、有內容 3、好問題 2、支持 34、雜訊 2

關鍵字（41）回一句＋私訊送清單。每則一樣溫度，但不要完全複製貼上。

潛在客戶
@帳號「我爸上個月也是住院沒申請到」
> 很常見，通常卡在診斷證明的日期。出院前請醫院開好就不用再跑。
> 如果想看你爸爸的狀況，可以私訊我，不用先傳任何證件。

好問題 → 做成短影音
@帳號「門診手術也能申請嗎？」34 個讚。這是一支短影音，用 #16。

雜訊（2）不回。

檢查：check.py 未發現高風險字詞
```

使用者說好才算數，回覆由使用者自己貼。
